# Library System

## Description

Simple Library Information System berbasis Laravel untuk mengelola data buku.

## Requirements

- PHP
- Composer
- MySQL
- Laravel

## Features

- Menampilkan data buku
- Menambahkan data buku
- Mengedit data buku
- Menghapus data buku
- Validasi data buku
